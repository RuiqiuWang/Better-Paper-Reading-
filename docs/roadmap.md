# 范围与路线图 / Scope and roadmap

## 当前已具备

- 七个论文阅读技能：检索、精读、工作台、追问改写/批注及偏好。
- research-manage：文件布局、课题/方法文档、实验证据与本地Git工具。
- research-evaluate：相关论文筛选、指标契约、固定样本、曲线/表格/日志协议，含2Dto3D与深度估计参考。
- research-optimize：正式实验前的小预算诊断与正确性工作流，分为跨领域、通用视频、两阶段2Dto3D；附一次真实推理案例摘要，不含通用自动测速执行器。
- Codex/Claude Code安装组合、升级备份，以及阅读/安装/Git行为测试。

## 下一步候选

按真实课题反馈逐项决定，并非已经实现的功能或固定交付承诺：

1. 在具体课题中接入协议，检验原始日志、评分和展示的一致性。
2. 从这些接入中提炼可复用的记录/绘图工具，保留不同训练栈的适配空间。
3. 对比run和baseline，检查协议/数据/输入条件是否可比。
4. 根据research-optimize在真实课题的接入结果提炼计时/配置扫描工具，继续验证训练与长视频，不把现有推理案例泛化成已验证能力。

优先完成一项可验证的小增量，再扩展下一项。当前没有通用训练调度器、后台服务器治理服务或“一键科研”自动流水线。
