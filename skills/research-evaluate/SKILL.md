# Research Evaluate

把“这个课题怎样证明有效”转成可追溯的评测协议和产物清单。通用记录规则与任务指标分开；不要把 PSNR/SSIM 或某篇论文的协议套给所有任务。本技能提供 agent 工作流和模板，不是已经接入训练器的日志服务。

用户的自然语言科研请求按可用的[自动触发表](../research-workflow/references/triggers.md)衔接；无需用户手动输入技能名。完整实验任务完成评测准备后进入性能阶段，单独评测设计请求则在原范围内结束；已由workflow协调时不重新递归路由。

## 从课题与论文开始

1. 先读课题 README、相关方法卡、已有协议和实验索引。明确任务输入/输出、研究假设、数据域、是否有 GT、训练还是纯推理、可用资源。影响主指标的未知项先标出；可继续完成无依赖的调研。
2. 搜索与任务直接相关的代表论文：优先用户指定方法、数据集/benchmark 原始协议、强 baseline，以及直接相关的新工作。已有 `read-search`/`read` 可用于发现与精读；未安装时使用可用检索工具，不能成为硬依赖。检索新课题时在线核验，记录日期、查询词和范围；不宣称一次检索穷尽领域。
3. 阅读论文评测章节、补充材料与官方评测代码。按任务/输入信息、数据划分、预训练数据、分辨率和计算预算判断可比性；不同条件分组。检索摘要只能用于发现，不能据此宣布核验了指标定义。访问失败标记未核验，继续其他来源，不虚构口径。
4. 输出精简证据表：论文与原始链接、为何相关、协议定位、指标、输入/数据条件、采用或排除理由。保留论文与代码不一致之处以及所选实现的理由、revision。数量以覆盖决策为准，不为凑论文数扩大调研。

## 形成可执行的记录方案

按 [协议和产物模板](references/protocol.md) 维护 `research/protocols/evaluation-v<version>.md`，在课题 README 链接它。开始时标 draft；已有授权且关键定义确定后标 active，不强制为每个常规决定再次询问。关键定义未定则不能伪称协议已冻结或结果可比。

- 每项指标写清来源、定义/实现版本、方向、单位、GT/辅助输入要求、预处理、mask、聚合方式、样本范围和记录频率。区分主指标、诊断指标及未采用指标；不是相关论文出现过的指标都必须记录。
- 决定曲线、汇总/逐样本表、可视化、运行日志、恢复状态各自保存什么、保存位置和成本。每个产物对应研究问题或故障诊断用途，避免无目的收集。
- 固定数值验证集及其中的可视化子集，保存实际样本 ID、帧窗口、预处理和推理随机性。不能只固定随机种子。按视频/场景等独立单位划分以防泄漏；最终测试集不用来周期调参或选 checkpoint。
- 训练 loss、学习率和耗时可高频记录；昂贵指标在固定验证子集上按 N 个 optimizer steps 记录，N=50 是起始候选，按预算调整并记录原因。完整验证、视频导出与 checkpoint 分别确定频率。纯推理任务用样本数/耗时，没有训练 loss 时标不适用。
- 2Dto3D 或深度估计读 [任务参考](references/task-profiles.md)。其他任务从论文证据推导，不强制输出图像指标；例如分类可记录准确率/F1，具体取舍仍由任务协议决定。

## 接入与结果维护

大规模训练或批量推理前，使用可用的 `research-optimize` 检查适用的性能记录，或在当前授权内做小预算瓶颈诊断和正确性试跑；沿用本技能定义的质量协议与固定样本。没有该技能时按同样原则先测代表性小样本、记录预算和回退配置。不能为加速静默改变指标、输入条件或删掉必要输出。

用户要求制定方案时交付协议与清单；要求接入现有代码时先核对训练器已有日志、评测与续训逻辑，仅补缺口。接入后用小型已有样本或隔离 fixture 验证原始记录与曲线一致、固定 ID/协议正确、恢复不混淆 step、NaN/缺 GT/部分完成不会变成正常分数。昂贵训练或服务器变更需在用户当前授权范围内。

优先使用现有 CSV/JSONL/TensorBoard 等输出，不无故更换栈。图是原始数据的视图；记录真实波动，不要求指标单调“增长”，平滑图仍保留原始值。对比表关联 run、checkpoint 和协议版本；不同协议不直接计算提升。

若 `research-manage` 可用，依其规则同步 run README、EXPERIMENTS、CHANGELOG 和本地 Git；否则直接维护这些既有文件，并遵守项目 Git 约定。小型协议/清单/摘要进代码仓库，大型预测、日志、权重和媒体留在 `/data`。只有用户明确要求才推送。已发布/已使用协议变更另开版本，旧 run 保留旧引用；不为了改善分数静默重选样本或修改口径。

最后只给用户：采用哪些指标及依据、会保存什么、主要未定项，以及当前是“协议已编写”“代码已接入”还是“真实实验已验证”。按小步迭代，不把模板完成说成训练监控已运行。
