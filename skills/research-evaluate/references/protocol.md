# 协议与产物模板

按任务裁剪以下模板，删除不适用项并简述原因。不要将示例字段当成已测事实。

## 文件分工

- `research/protocols/evaluation-v1.md`：下面的来源、指标、产物和选择规则；纳入 Git。
- `research/manifests/<split>-v1.jsonl`：小型实际样本清单；共享发布后的权威位置可为 `/data/<topic>/manifests/`，协议记录路径和内容哈希。两处不独立编辑。
- `/data/<account>/projects/<topic>/runs/<run-id>/`：实际参数、原始记录与媒体；沿用既有 metrics/figures/predictions/logs/checkpoints 目录。
- 课题 README 导航；EXPERIMENTS 写具体结果及证据；CHANGELOG 写协议/样本变化原因。不得只链接图片而丢失数值。

## 最小产物清单

| 产物 | 内容 |
|---|---|
| resolved_config.yaml | 实际解析参数、训练/推理种子、初始化权重、数据/代码/环境及协议版本引用；避免凭据 |
| metrics/train.jsonl | run_id、segment_id、optimizer_step、timestamp、累计训练秒、总loss/分项、学习率；按协议加入吞吐、data_wait、峰值显存 |
| metrics/validation.jsonl | run/checkpoint/协议/manifest版本、split、step、时间、指标、实际与预期样本数、状态 |
| metrics/per_sample.csv | 检查点、样本/视频ID、指标、有效像素/帧数、成功或失败状态；规模大时分片 |
| metrics/summary.json | 按域/方法/种子汇总；明确聚合和完整性，保留各run值，单次实验不虚构标准差 |
| figures/ | 原始与可选平滑曲线、固定样本对比图；标明坐标/单位/协议，支持step与耗时横轴 |
| predictions/ | 按checkpoint和固定样本ID保存原始预测、mask及预览视频；数值评分使用原始输出，不回读有损预览 |
| logs/ | 开始/结束/失败/恢复事件及带时区时间、命令、硬件与计时条件、stderr；NaN/OOM和跳过样本可追溯 |
| checkpoints/ | last和按验证主指标选出的best，必要里程碑；续训保存模型、optimizer、scheduler、AMP scaler（若使用）、RNG和采样进度 |

文件名可复用现有工程命名，字段可以引用已有配置，不要求重复存储。纯推理没有train日志或续训状态时写不适用。每次验证可保留标量与逐样本分数；大型原始预测/视频按best、里程碑和固定子集保留，避免每50步完整导出。

## 可比性与续训细节

- 50步指实际 optimizer 更新次数的候选约定；记录梯度累积与混合精度溢出跳步。已有工程采用其他计数时显式映射，不能静默改变历史step含义。
- 恢复事件记录源checkpoint、segment_id和父run。回退到较早checkpoint重跑时保留各段标识，绘图按所选分支重建，不能把不同轨迹同step直接平均。
- 记录墙钟起止、累计训练时长、累计验证/导出时长；恢复停机时间与计算时间分开。CUDA异步计时须采用框架事件或适当同步，推理报告warmup/IO边界和batch条件。
- DataLoader瓶颈用数据等待与吞吐对照判断；`num_workers`、线程数、预取和pin_memory一并记录。需要调优时，在获授权的小样本预算内比较吞吐/内存后决定，不能假定worker越多越好或承诺GPU一定是瓶颈。
- 无效/非有限值与样本失败单独计数；不能填0或静默排除来提高平均值。完美重建的PSNR可为+∞，按预先约定报告，不混同NaN。只有划分、输入信息、指标口径等一致才汇报相对提升。
- 视频帧相关，论文级不确定性估计以独立视频/场景或独立训练run为单位，不能把相邻帧冒充独立实验。完整测试仅在既定节点执行，不据此反复挑checkpoint。
