# 论文原图

使用图示有助于理解时，从实际读取的 HTML figure/img/src/srcset 和 figcaption 建立图号、图片 URL、图注与所属章节的对应；相对 URL 按论文页面 URL 解析，不假定图片只叫 xN.png。

将选中的原图缓存到 `<STORE>/_cache/<paper-id>_figs/`，已有有效缓存可复用。验证下载内容确实是声明的图像格式而非错误页。正文使用相对 HTML 笔记位置的图片路径，使笔记离线可看。提供清楚的替代文本、原文图号与图注；讲解者补注单独标明。可以使用 `figure.fig` 和 `figcaption .mynote` 类名。

图的数量服从解释需要。若写作时使用占位符，在交付前全部替换成实际图像或明确的缺失说明。获取不到原图时说明限制，不能凭空画图冒充论文原图。
